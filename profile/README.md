Midnight Oil Drafts

A public learning journal and portfolio. I pick the skills I want to refresh or learn, find a real problem they can solve, and turn the finished project into a tutorial anyone can follow, including beginners.

Start with the site: [midnightoildrafts.com](https://midnightoildrafts.com/)

What’s here: project repos, each tagged by language, technology, and skill status (applied, refreshing, or learning).

A note on AI: I use AI to help build, explain, and draft. I test the code, cross-check against official docs, and review everything before it’s published.
